# 北京银发低强度旅行参考（公开模拟样例）

> 本文是用于 RAG 召回评估的安全模拟目的地知识，不代表真实库存、实时价格、实时天气、开放状态、预约结果、无障碍设施现状或供应商承诺，也不提供锁价与代订。场馆开放、预约、接驳和无障碍服务须在出发前通过官方渠道二次核验。

## 适用边界

本样例面向有长辈同行、需要低强度与充分休息的北京行程。规划时以“每天一个核心区域、上午一个重点、午间固定休息、下午轻量活动”为主，不用景点数量换取完整度。

## 核心区域与节奏

- **东城核心区**：历史文化点集中，但场馆面积、排队和步行距离可能较大。每半天只保留一个重点，入口、安检、接驳和休息点均需预留缓冲。
- **西城核心区**：适合将公园、街区或室内文化点组合成低强度半日路线，避免连续跨区。
- **奥林匹克公园等开阔区域**：空间较大，风、日晒和步行距离会放大体力消耗；只选短动线观景点，并提前确认落客与返程位置。

住宿优先选择核心城区或当天主要活动区附近，减少跨城通勤。房间和公共区域是否有电梯、无台阶入口、适用卫生间、淋浴扶手及较短房间动线，应向酒店逐项确认，不能仅根据“适老”标签判断。

## 午休与低强度安排

- 上午安排一个主要文化点，连续步行一段时间后主动休息，不把多个大型场馆串联。
- 午餐后预留约 1.5-2 小时返回酒店或安静室内空间休息。
- 下午只安排一个可随时缩短的公园、街区或室内点，晚间不强制增加项目。
- 每天保留机动时段；若长辈出现疲劳、疼痛或不适，应立即缩短或取消后续活动。

## 无障碍与电梯核验清单

出发前应向场馆或酒店官方渠道确认：

1. 无台阶入口、无障碍通道及电梯当前是否开放；
2. 轮椅借用、无障碍卫生间、休息座椅和陪同人员规则；
3. 车辆落客点到入口的实际距离、地面坡度及排队安排；
4. 酒店电梯、房间楼层、浴室防滑与扶手条件。

上述设施可能因维护、客流或临时管控变化，本文不作可用性承诺。

## 天气 Plan B

- **高温或强日晒**：缩短广场、公园等户外停留，改为单个可确认开放的室内场馆，并增加补水和午休时间。
- **降雨或大风**：取消长距离步行与开阔区域，优先选择交通落客点较近、室内休息条件明确的文化场馆或酒店周边活动。
- **寒冷或空气状况不适合户外活动**：采用“酒店休息 + 一个室内点”的最小行程，是否外出以长辈身体感受和权威提示为准。

室内 Plan B 同样需要核验预约、开放日期、无障碍入口和电梯状态，不能把“室内”自动视为低风险。

## 3 天低压力参考结构

**Day 1**：抵达与入住 -> 酒店周边轻量活动 -> 提前休息

**Day 2**：核心城区一个重点文化点 -> 午餐与午休 -> 同区域短动线活动或室内 Plan B

**Day 3**：根据长辈状态选择一个轻量点 -> 午休或返程缓冲 -> 返程

本结构只用于规划参考，不包含实时交通班次、门票或酒店价格、库存、预约成功及履约承诺。
